# Authority Order

If two documents appear to overlap, use this precedence:

1. **Project and Brand Brief** — product intent and scope.
2. **UX and Page Architecture** — page content/responsibility.
3. **Design System** — visual rules.
4. **Responsive, Accessibility and Interaction** — behaviour and quality requirements.
5. **Frontend Technical Architecture** — implementation mechanics.

A technical convenience should not override an approved UX or design decision without a clear reason.
